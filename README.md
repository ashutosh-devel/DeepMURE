# DeepMURE

**Deep Self-Supervised Despeckling via Monte Carlo Multiplicative Unbiased Risk Estimation**

This repository will host the official PyTorch implementation of DeepMURE, a self-supervised framework for despeckling SAR images, together with the SpeckleFormer architecture described in the paper.

## Code availability

The paper has been submitted to IEEE Transactions on Image Processing and is currently under review. We intend to make the code public here once the review process is complete and the codebase has been cleaned up and refactored. We are not able to commit to a release date at this time.

If you would like to be notified, you can watch or star this repository.
